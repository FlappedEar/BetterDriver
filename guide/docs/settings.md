# Settings

**Settings** is one page of topics. Each line says what is set now; tap it to open its own page.
Tapping **Settings** in the bottom bar again goes back to the topics.

| Topic | What is in it |
| --- | --- |
| **Equipment** | Receivers, cameras, sensors and OBD-II adapters, with whether each can be reached now. See [Equipment](equipment.md). |
| **Cars** | Your cars' names and notes, **Add car**, and units (km/h, °C). See [Car](car.md). |
| **Tracks** | Circuits near you, your saved tracks and the track editor. See [Drive and tracks](drive.md#tracks). |
| **Track screen** | **Track screen brightness** (full brightness while the track screen shows, on by default) and **Sound when GNSS is lost** (off by default). **Tiles** for both track screens, one layout per car; see [Choosing what a tile shows](track-screen.md#choosing-what-a-tile-shows). |
| **Video** | The video mode of each camera the app controls, and the free storage. |
| **Spoken coach** | How much the coach says, picked corners, headset delay, learning laps, language, voice, speed and pitch. See [The spoken coach](coach.md). |
| **App** | Theme (always dark), the spoken coach, permissions and what each one that is off stops, the version and updates, backup and restore, **Run setup again**, **About and credits**. |
| **Diagnostics** | **Share log**, **Clear log** and the **Camera test**. |

## Diagnostics

The app keeps one continuous log across all sessions and restarts; it is kept until you clear it.

- **Share log** sends it as one zip. After a drive, share it once: the app's recording checks
  (GNSS rate and gaps, video sync, cue timing and the rest) are worked out from it.
- **Clear log** asks first and shows the size.
- **Camera test** records 1080p · 60 twice, 12 minutes each, with and without writing the MP4,
  and shows the camera's frame rate and skipped frames for each part. It stops if a session
  starts.

Each session's own checks are on its **Data quality** card in the
[lap analysis](analysis.md#summary).
