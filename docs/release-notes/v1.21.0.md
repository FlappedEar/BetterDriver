1.21.0: Bluetooth OBD adapters found by their service, recording hardening, and the iPhone and iPad catch up with Android's session review.

What changes for the driver:
- A Bluetooth LE OBD adapter with a name the app does not know is offered in Add equipment when it advertises an ELM327 serial service (FFF0, Vgate's E7810A71 or 18F0); LELink and Konnwei KW902/KW903 names count too (#430).
- A recording whose start fails part-way, for example in the timing or coach setup, now stops cleanly instead of leaving its writer running (#436).
- A failed video write is reported at once ("writer: ...") instead of showing up later as a stalled writer (#436).
- Importing a bundle or backup that holds the same file twice is refused (#436).
- On the iPhone and iPad: Progression at this track, Coach review, every pass through a corner, the Map tab's Laps view, Compare laps from any sessions, driving-state strips, corner corrections in the track editor, Make a track from a session (#411), and coach corner flags in Where time goes (#434).
- On the iPhone: the track screen no longer slows down during a long recording (#437); dropped camera frames are counted and an MP4 is offered for export only once it has finished (#436); the log shows the track screen's frame time (#430) and its size in KB under a megabyte (#429).
- Session storage, recording log lines, quality checks, the log reader and the coach run are now code shared by the Android and iOS apps; Android's behaviour and files are unchanged (#422, #425, #432, #433).
