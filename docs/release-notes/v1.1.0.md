1.1.0: an OBD-II page in Settings shows the Wi-Fi adapter's connection and the car's values live (FBBD-261, UI-104 B).

What changes for the driver:
- Settings › Devices has a new Car data section with an OBD-II row; Settings › Car › Car data (OBD-II) opens the same page. The row says Recording, Connecting or No adapter while a session records, and Wi-Fi adapter otherwise.
- The OBD-II page shows whether the adapter answers, the adapter, protocol and battery voltage at the OBD port, then every value the car sends (RPM, speed, throttle and the rest) with how many times a second it arrives.
- During a session the page shows what the recorder receives. With no session recording, the page connects to the adapter itself while it is open, so the adapter can be checked before driving: join the adapter's Wi-Fi, switch the ignition on and open the page. It lets go of the adapter as soon as a session starts, and the recorder takes over.
- Recording OBD-II is unchanged from 1.0.1. The track screen is unchanged.
