Alpha 0.3.27: fixes from the 2026-10-16 midday drive log.

What changes for the driver:
- **Video starts when the phone is already warm.** If a session started while the phone was already hot, the first 1080p file was stopped before it held a frame (CameraX error 8), so the start of the session had no video. Video now opens at the quality step the phone is already at.
- **No false "dropped samples" FAIL on the RaceBox Micro.** The Micro also skips its whole-second message before it has a fix. That skip is now left out of the report and no longer asks for a faster Bluetooth link every 30 s. On a Mini, a lost message without a fix still counts as dropped.
- **The GNSS fix delay is always logged.** The debug log now says `gnss fix age 0 ms, on time (...)` or `not measured: ...` when no age is found, live and when a session is opened. Before, nothing was logged in those cases. An on-time result also clears an older live delay, so the coach stops allowing for it.
