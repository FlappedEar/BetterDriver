Alpha 0.3.14: fixes from the 2026-10-14 drive log (#168). Use this build for the next drive and the headset test.

What changes for the driver:
- **The track screen shows the RaceBox's real rate from the first second of a fix.** At a fresh fix it counted only the fixes in the last second and showed "8 Hz" while the RaceBox sent 25. It now shows the rate measured from the message interval.
- **No 2 s of video lost when a new session starts right after the last one.** The camera waited 5 s after a stop before it could start again; it now ends as soon as the last video file is closed.
- **The quality report counts the RaceBox's whole-second skip apart (FBBD-218, FBBD-170).** The RaceBox does not send the message on a whole second while it has a fix. The 2026-10-14 log showed 997 of 1026 missing messages on a whole second, and 25 messages a second whenever there was no fix, so this is the device, not the Bluetooth link. "Dropped" now judges only the other missing messages, and says how many whole-second skips were left out.
- **A link drop while parked at the end of a session is not judged as a reconnect (FBBD-43).** The one drop in the 2026-10-14 log was in the garage, without fix, 7 s before the stop.
- **The RaceBox stats line no longer counts the clock jump when the fix comes as millions of missing messages.**
