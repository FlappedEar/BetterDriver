1.5.0: a new look for every screen outside the car, from Arek's picks in UI review rounds 32 to 37 (FBBD-277, FBBD-274, FBBD-276).

What changes for the driver:
- Drive (UI-130 C, UI-131 A, UI-132 B): the devices of the session as chips on top, a bigger START ring (250 dp, was 190), and the session's choice in one line under it ("Corolla · RaceBox Micro 3241", "2 of 3 cameras on"). Change opens a sheet with the car, the receiver and a switch per camera. Last session is no longer on Drive (FBBD-276); it is the first row in Sessions.
- The bottom bar has a Car item (UI-136 B): the next session's car, titled with its name (UI-134 B), with the adapter's state and the car's live values; Edit opens its name and notes (UI-133 B). The old "Car data (OBD-II) · Later" row is gone (FBBD-274).
- Settings is one page of topics (UI-137 B): Equipment, Cars, Tracks, Track screen, Video, Spoken coach, App and Diagnostics, each line saying what is set, each opening its own page. The rows inside are the ones the tabs had.
- Settings › Equipment groups the items by kind and says whether each can be reached now (UI-138 B): In range or Not seen for Bluetooth LE devices while the page looks for them, Built in, Start by hand, Paired for a Classic device (a scan never hears one), Over Wi-Fi. Live values of the car are under Car data (UI-135 B); Cars has names and notes only.
- Sessions lists one row per session, grouped by day (UI-139 C): time and track, car, length, timed laps and what was recorded (Video, OBD, HR), the best lap in purple. A tap opens lap analysis; ⋮ opens everything else (GoPro video, coach review, export, share, delete). A row says while something runs for it.
- Track screen: the status strip is quiet while all is fine (UI-141 B): a green dot and a name, values only for heart rate, the recording time and anything wrong, in amber. With the spoken coach off, the coach line is left out and the tiles grow into its place (UI-142 B).
- Plain lists instead of grey cards (UI-143 B), and FlappedEar amber as the accent colour of buttons, links, the selected item and START (UI-144 B).
- Lap analysis keeps its five tabs (UI-140 A). Recording, timing, video, coach and session files are unchanged from 1.4.2.
