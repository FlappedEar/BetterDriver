1.26.0: the iPhone and iPad back up, restore and share tracks with files the Android app opens too, and the iPhone gets Android's first-run setup.

What changes for the driver:
- iPhone and iPad: Settings › App › Back up and Restore (Merge or Replace), Tracks › Import and Share in the track editor; .bdbackup and .bdtrack files open from Files or AirDrop and are interchangeable with the Android app (an iPhone backup carries no Android app settings). Android's backup and track sharing now run on the same shared code with the same files (FBBD-372, #470).
- iPhone: a first-run setup checklist with the same four steps as Android (permissions, GNSS receiver, cameras, car), and Settings › App › Run setup again; the iPad, for review only, opens on Sessions, as the Android tablet. Android's setup steps and texts now come from the same shared code (FBBD-371, #469).
- A flaky iPad UI test of the composite-lap video now waits for the pick before it checks Watch; no change in the app (FBBD-370, #474).
