Alpha 0.3.12: review fixes only, no new features (FBBD-220). Use this build instead of 0.3.11 for the next drive and the headset test, so the drive log's responsiveness checks count the right recordings.

What changes for the driver:
- **An ANR that ends an unfinished recording counts against it (FBBD-41, #163).** When Android ends the app as not responding and the recording has no stop, the quality report now counts that ANR against the recording it ended. Before, it was missed. A start-up during an unfinished recording is no longer graded again for the next one.
- **An exit record that could not be read is reported as such (FBBD-41, #163).** If Android refuses the read, the Responsiveness section says the ANR count "could not be read" instead of reporting zero. Start-up time is now also measured when the app opens on the restore-error screen.
- **A one-axis accelerometer is never used as both forward and left (FBBD-221, #164).** With an external receiver that sends only one accelerometer axis, that axis is used for at most one direction; the other comes from GPS. The RaceBox Micro and the phone always send all three axes and are unaffected.
- **Documentation (#162).** The 0.3.9 notes now state that video start points are computed and tested, but not that the players start there. The analysis README describes when segments are re-proposed for a changed layout.
