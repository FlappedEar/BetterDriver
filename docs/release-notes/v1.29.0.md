1.29.0: Google's satellite photo on Android in the track editor and under the perfect lap in 3D, and the OBD page names the Bluetooth LE OBD-II adapter in use.

What changes for the driver:
- Android: the track editor and the perfect lap in 3D can use Google's satellite photo. In the editor, Map › Add Google key… takes your own Google Map Tiles API key, limited to Android apps with the package and certificate SHA-1 the dialog shows; with a key Google comes first, then MapTiler, then OpenStreetMap, and Map still picks another. Google's tiles stay in memory only, so a saved 3D video over Google's photo keeps the drawn road, and the credit names the photos' owners. Same as the iPhone and iPad since 1.28.0 (FBBD-412, #501).
- A Bluetooth LE OBD-II adapter is named on the OBD page and in Settings as the adapter in use, no longer as the Wi-Fi adapter listed before it; on iPhone the Wi-Fi adapter's page shows its address (FBBD-423, #500).
