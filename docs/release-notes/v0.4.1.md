Alpha 0.4.1: phone video stops only at Android's thermal shutdown, the session report is silent about the phone unless a shutdown happened (FBBD-250), and two coach fixes (FBBD-243, FBBD-27).

What changes for the driver:
- Phone video stops only when Android reports thermal shutdown (status 6), and then it finishes the file first, also when the file has no frame yet or the camera is restarting. No other phone state stops video, with Ignore phone temperature on or off.
- The session report has no thermal or battery rows any more. Only an Android thermal shutdown adds a Thermal shutdown section, which fails and checks that no phone video file was left unfinished. Stored reports are made again in the new format.
- The video mode dialog no longer talks about the phone's state.
- A coach praise still waiting when a cooling-down lap ends is dropped instead of being said on the next lap (#226, FBBD-243).
- The per-straight check: a coach praise followed by the straight's corner cue no longer counts as an extra cue on that straight (#224, FBBD-27).
- Lap timing is unchanged from 0.4.0.
