Alpha 0.4.2: 2.7K·60 phone video through BetterDriver's own encoder with gapless file cuts (FBBD-246, FBBD-248), and the Ignore phone temperature switch is gone (FBBD-251, UI-102 A).

What changes for the driver:
- 2.7K·60 no longer uses Android's MediaRecorder. The camera draws into BetterDriver's own encoder, which runs at real-time priority, and the app writes the MP4 files itself, cutting each file at a keyframe so the next starts one frame after the last, with sound on both sides (#227). On 0.4.0 2.7K·60 held 49.8 fps and the hand-over at 3.8 GB failed and dropped the session to 1080p·60.
- Each 2.7K file's log line adds the frames the camera delivered and the encode time, so the next log shows whether the camera or the encoder holds frames back.
- Settings › Diagnostics no longer has Ignore phone temperature (#230). Since 0.4.1 phone video stops only at Android's thermal shutdown.
- Lap timing and the coach are unchanged from 0.4.1.
