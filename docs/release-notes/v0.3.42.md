Alpha 0.3.42: the coach's voice, speed and pitch can be changed (FBBD-240).

What changes for the driver:
- **Settings › App › Spoken coach** has a **Voice** row and **Speed** and **Pitch** sliders (Arek's picks UI-90 A, UI-91 B). Speed runs 0.8× to 1.5× and pitch 0.7× to 1.3×, in 0.1 steps; both start at 1.0×.
- The Voice row opens a page listing the phone's offline English voices, grouped by accent (UK first, then US, Australia, India, others), each as "Voice N". ▶ plays the sample cue in that voice; tapping a voice uses it and plays the sample. **More voices in Android settings** opens Android's text-to-speech settings, where more voices are downloaded; the list reads again on return.
- Only voices installed on the phone that need no network are offered, so a cue never waits for a download. A voice that is later removed falls back to the phone's English voice, as before.
- Live and pre-rendered cues both use the chosen voice, speed and pitch; pre-rendered clips render again when any of the three changes.
- The log writes "voice NAME, speed R, pitch P" when the voice is set.
- Recording, lap timing, video, analysis and storage are unchanged from 0.3.41.
