1.3.0: heart rate after a session in Lap analysis (FBBD-225, UI-107 A, UI-108 B, UI-109), and a track screen with ten data tiles and a second screen (FBBD-262, UI review round 31).

What changes for the driver:
- Lap analysis › Summary has a Heart rate card under the lap times: the session's average, highest and lowest heart rate, the strap's name and how many minutes of heart rate it holds.
- Lap analysis › Laps has a column with each lap's average and highest heart rate (bpm avg · max).
- Only what was recorded is shown: a session without heart rate has no card and no column, and a lap without heart rate has an empty cell, never 0 bpm. The lap comparison has no heart-rate chart.
- Track screen (FBBD-262): the sector strip is gone. Below the coach line there are now ten tiles in two rows (UI-120 C), so the delta and lap times are a little smaller. A tile can show speed, G, satellites, delta, lap time, last, best or predicted lap, lap number, any OBD-II value the car sends (coolant, oil, intake air, RPM, throttle, battery voltage and the rest) or heart rate.
- Swipe left for a second screen of twelve tiles (UI-121 B); two dots after the recording time show which screen is on (UI-122 A). A swipe never stops the session; holding 3 s anywhere still does.
- With the car stopped, hold a tile 1 s to choose what it shows (UI-123 B), from a list grouped by source with each channel's value now (UI-124 A). The choice is kept for every session. Settings › Recording no longer has Track screen tiles.
- A new install shows Speed and G, the other tiles empty (UI-125 B); a setup from before keeps its tiles. A tile whose channel sends nothing in a session is left out while driving and the others widen (UI-126 B); a value that stops arriving shows a dash.
- Timing, video, coach and storage are unchanged from 1.2.0.
