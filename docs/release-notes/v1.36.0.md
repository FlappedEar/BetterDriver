1.36.0: a coach that speaks where the line plan looks, and about the corners after short straights; a fixed iPad Share log.

What changes for the driver:
- The coach: a corner whose own straight is too short for any cue (Silesia Turns 6, 11 and 1 follow 1.6-2.2 s straights) now gets its cue one straight earlier, in its shortest form ("Turn 11, brake at 75"), when the corner before it has nothing to say. It still ends before the next braking zone, is judged on that corner's next pass, and is not repeated on its own straight (FBBD-404, #617, 685daf2).
- The coach: it has a corner in every track corner, so it measures and aims at the same corners and the same target lap as the line plan on the Map tab; corners without a speed minimum of their own (Jastrząb Corners 2, 10, 12; Silesia Corners 7, 8, 11/12) are now coached. Saved coach references are rebuilt once (FBBD-405, #616, da25283).
- The coach: each corner cue logs the length it was planned to take (`say_ms`), and the session quality report compares it with the sound's real length per language (`coach.say_length`, info) (FBBD-406, #615, f75218f).
- iPad: **Share log** in **Settings › Diagnostics** is no longer covered by the navigation bar (FBBD-486, #614, 27f7725).
- Behind the scenes: the iPad layout test no longer races the list's slide-away animation (FBBD-406, #615, f75218f); the Share entry point tests run on every iPad pull request (FBBD-486, #614, 27f7725).
