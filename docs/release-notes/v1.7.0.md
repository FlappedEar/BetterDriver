1.7.0: a camera test in Settings › Diagnostics records 1080p · 60 for 12 minutes with the MP4 and 12 without, to show whether writing the file holds the camera back (FBBD-278).

What changes for the driver:
- Settings › Diagnostics has a new row, Camera test (UI-150 A). It records 1080p · 60 twice with the same settings, sound included, 12 minutes each (UI-151 A). Part 1 writes the MP4 as a session does. Part 2 runs both encoders and hands each buffer straight back, writing no file. Part 1's video is deleted at the end.
- While it runs, the screen shows the part, a progress bar, the time left and each part's camera rate and skipped frames, with a Stop test button. At the end both parts are side by side, with Share log (UI-152 A). The screen stays on during the test.
- The log gets the same lines once a minute as a session's video ("camera frames", "camera threads", "encoder timing"), a line per part, and one for the whole test.
- Starting a session stops a camera test that is running; the session's video takes the camera. A test cannot start while a session records video.
